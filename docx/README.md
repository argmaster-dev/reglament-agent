# Исходный корпус

Четыре регламента, выданные организатором для задачи «Поиск ответов по корпоративным документам». Документы обезличены. Организатор устно разрешил публиковать их в репозитории.

| Файл | Подразделение | Этапы | SHA-256 (первые 12) |
|---|---|---|---|
| Организация проектной деятельности Тех дирекции.docx | Техническая дирекция | пресейл, реализация | `d0a84128c45b` |
| Проектная деятельность ДБРЦТ.docx | ДБРЦТ | пресейл, реализация | `be8a86386276` |
| Проектная деятельность Дирекции ИБ.docx | Дирекция ИБ | реализация | `35c9d6494027` |
| Пресейловая деятельность Дирекции ИБ.docx | Дирекция ИБ | пресейл | `e39235e9a425` |

Подразделение и этапы в самих файлах не указаны. Их задаёт служба качества при загрузке документа. Для первичной загрузки они записаны в [`documents.toml`](documents.toml).

Файлы хранятся без изменений. Документы и их новые редакции загружает служба качества через админ-страницу приложения. Этот каталог служит только начальным набором для стенда и тестов.

## Глоссарий

[`glossary.tsv`](glossary.tsv) — утверждённый заказчиком словарь сокращений: 48 записей, получен 26.11 в канале трека. Колонки: сокращение (варианты через запятую) и расшифровка. Используется для расширения запроса при поиске, в проверке ролей и для ответов на вопросы вида «что такое ТКП». В регламентах встречаются и другие формы: например, «Менеджер по продаже решений (SS)» в регламенте ТД. Такие синонимы задаются в коде отдельно.
