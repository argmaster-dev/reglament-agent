# Демонстрационные правки регламентов

Файлы в этой папке не входят в основной корпус и не загружаются при первичном заполнении стенда.
Они нужны, чтобы показать замену документа новой версией.

| Файл | Исходный документ | Что изменено |
|---|---|---|
| `ДБРЦТ v2 (демо-правка п. 1.5).docx` | `Проектная деятельность ДБРЦТ.docx` (`dbrct-project`) | В п. 1.5 «3 рабочих дня» заменено на «5 рабочих дней». Остальной текст не менялся. |

Это демонстрационная правка, а не настоящая новая редакция регламента: срок в п. 1.5 изменён только для показа.
Файл собирается скриптом `scripts/make_demo_v2.py` (`uv run python scripts/make_demo_v2.py`).
