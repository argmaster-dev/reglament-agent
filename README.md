# Агент поиска ответов по регламентам

Прототип для задачи «Поиск ответов по корпоративным документам» конкурса «ИИкузница», трек «Аналитик данных».

Сотрудник задаёт вопрос в чате. Агент отвечает коротко, своими словами, со ссылками на пункты регламентов. Если ответ зависит от подразделения или этапа, агент уточняет. Если ответа в регламентах нет, агент создаёт обращение в службу качества. Ответ эксперта пополняет базу знаний, и на повторный вопрос агент отвечает уже по нему.

## Состояние

Идёт спринт 26–28 ноября 2026 года. Разделы «Запуск» и «Архитектура» будут заполнены по ходу работы.
